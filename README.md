# TU PRIMERA SEMANA COMO DATA SCIENTIST

Este repositorio reúne los ejercicios y materiales de una experiencia formativa como Data Scientist. Se trabaja con Python y Jupyter para recorrer las primeras etapas de un proyecto de datos, desde el análisis exploratorio de datos, pasando por ver algunas técnicas de Business Analytics y trabajando con modelos de Machine Learning para obtener predicciones que permitan ejecutar acciones directas sobre el negocio.

El caso práctico utiliza información sobre abandono de empleados. La idea es aprender a convertir esos datos en análisis que ayuden a comprender el problema y sirvan como punto de partida para construir un modelo de machine learning que permita crear un cuadro de mandos con la información necesaria para conocer el estado de riesgo de fuga de la plantilla y tener acciones de retención personalizadas.

## ¿Qué haremos estos días?

- **Día 1:Business Analytics.** Prepararemos nuestro entorno de Codespases, creando la cuenta, clonando este repositorio y familiarizandonos con los datos del caso. Posteriormente revisaremos la estructura y calidad de los datos, analizaremos los valores ausentes y comenzaremos el análisis exploratorio (EDA), incluyendo variables categóricas.

- **Día 2: Machine Learning.** Daremos los primeros pasos en el uso de técnicas de Machine Learning aplicadas al caso de abandono de empleados.

- **Día 3: Dashboard Interactivo.** Desarrollaremos un cuadro de mandos con Streamlit, que permita identificar claramente los empleados en riesgo de abandono y conectaremos con un LLM para obtener un informe personalizado.

## Herramientas

- Python
- Jupyter Notebooks
- NumPy y pandas para trabajar con datos
- Matplotlib para visualizarlos
- scikit-learn para Machine Learning
- Streamlit para generar el dashboard
- Gemini para crear una api key y obtener resultados en lenguaje natural
